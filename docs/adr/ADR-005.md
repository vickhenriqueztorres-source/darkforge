# ADR-005: APIs oficiais primeiro e limites explícitos para dados públicos

- **Status:** ACCEPTED
- **Data:** 2026-11-16
- **Requisitos relacionados:** `CH-005`..`CH-008`, `AN-004`, `AN-005`, `RES-001`..`RES-007`

## Contexto
Canais próprios possuem métricas privadas via OAuth; concorrentes possuem apenas metadados e contagens públicas observáveis.

## Decisão
Usar **APIs oficiais do YouTube** (Data API, Analytics API, Reporting API quando elegível) com escopos mínimos OAuth e `QuotaLedger` compartilhado com prioridade para sync de canais próprios sobre pesquisa pública.

## Consequências e invariantes
- Proibido scraping indiscriminado, contorno de autenticação, robots ou termos de uso.
- Proibido inferir ou exibir métricas privadas de concorrentes (CTR, retenção, impressões, receita) como fato.
- Métricas ausentes, atrasadas ou não aplicáveis são representadas explicitamente (`unknown`, `delayed`, `partial`, `not_applicable`), nunca como `0`.
