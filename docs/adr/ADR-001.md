# ADR-001: Web UI local como interface principal; EXE somente como launcher opcional

- **Status:** ACCEPTED
- **Data:** 2026-11-16
- **Requisitos relacionados:** `AUTH-001`..`AUTH-006`, UI/UX PRD §10, RNF §13.5

## Contexto
O material histórico previa interface desktop (CustomTkinter/EXE). O Channel OS precisa de dashboards analíticos, painéis de evidências, curadoria RAG, calendário editorial e acompanhamento de jobs assíncronos.

## Decisão
A interface principal é uma **Web UI local (Next.js / React / TypeScript)** servida no PC e acessada pelo navegador. Um eventual `.exe` no futuro atua exclusivamente como launcher/empacotador que inicia os processos locais e abre o navegador, nunca como segunda aplicação.

## Consequências e invariantes
- A Web UI nunca executa FFmpeg/FFprobe nem SQL privilegiado.
- A Web UI nunca recebe `service_role`, `DATABASE_URL` ou tokens OAuth.
- Acessibilidade por teclado, foco visível, contraste claro/escuro e estados explícitos são obrigatórios.
