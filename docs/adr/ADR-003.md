# ADR-003: Command Bus e Job Manager únicos compartilhados com o DarkForge

- **Status:** ACCEPTED
- **Data:** 2026-11-16
- **Requisitos relacionados:** `JOB-001`..`JOB-006`, `PROD-001`..`PROD-005`

## Contexto
O código-fonte do núcleo DarkForge não está presente neste repositório (auditoria `SP-00-T02`), apenas artefatos históricos (`media_vertical_v1`). Manter duas filas ou dois catálogos de jobs causaria divergência de estado e falso sucesso.

## Decisão
Existe um **único catálogo lógico de jobs** e um **único Command Bus** no Channel OS (`core/jobs/`), persistido no Supabase Postgres. Quando o executor DarkForge for conectado em `SP-08`, a integração ocorre exclusivamente via `DarkForgeGateway` com comandos idempotentes e reconciliação de estado.

## Consequências e invariantes
- Toda operação assíncrona passa pelo Command Bus com `idempotency_key` e `correlation_id`.
- Se o núcleo DarkForge não expuser contratos compatíveis em `SP-08`, o bloco `PROD-001..005` é marcado `BLOCKED` sem criar executor paralelo ou produção fake.
