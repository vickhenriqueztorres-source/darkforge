# ADR-004: Supabase Postgres como fonte transacional única; sem segunda verdade SQLite

- **Status:** ACCEPTED
- **Data:** 2026-11-16
- **Requisitos relacionados:** `AUTH-003`, `JOB-004`, `PROD-004`, RNF §13.2, §13.4

## Contexto
Tratar SQLite ou arquivos locais como banco durável gera perda de dados, conflito de versão e ilusão de operação offline.

## Decisão
O **Supabase Postgres** é a única fonte de verdade durável para workspaces, canais, métricas, pesquisas, conhecimento, oportunidades, briefs, jobs, leases, outbox e manifests. Cache local em `%LOCALAPPDATA%\DarkForge\` é estritamente descartável e somente leitura.

## Consequências e invariantes
- Proibido dual-write permanente entre SQLite legado e Postgres para a mesma entidade.
- Sem conectividade com o Supabase, nenhuma escrita é confirmada nem job concluído; um render local sem manifest remoto fica `LOCAL_COMPLETED_PENDING_SYNC`.
