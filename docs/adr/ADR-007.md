# ADR-007: Provider Router para IA local e externa sem fallback externo silencioso

- **Status:** ACCEPTED
- **Data:** 2026-11-16
- **Requisitos relacionados:** `KNOW-008`, `OPP-001`, `TITLE-002`, `THUMB-003`, RNF §13.1

## Contexto
O PC alvo possui 16 GB RAM e GPU integrada Intel HD 4600 (sem GPU dedicada). Modelos locais podem ser limitados ou indisponíveis, mas dados privados de canal não podem vazar para nuvem externa sem ciência do usuário.

## Decisão
Centralizar todas as chamadas de IA em um **Provider Router** separado em quatro papéis (`classification`, `generation`, `embeddings`, `vision_ocr`), com registro de provedor, modelo, limites e orçamento.

## Consequências e invariantes
- Nenhum model ID fica hardcoded no domínio.
- Indisponibilidade de modelo local **nunca** dispara fallback para provedor externo sem consentimento explícito do usuário; o job transita para `BLOCKED` (`RECOVERABLE`).
- Antes de envio externo, a UI informa as categorias de dados enviadas; segredos e tokens OAuth são removidos por redaction.
- Nenhuma chamada de IA ocorre dentro de transação aberta do Postgres.
